Projects

Things I've built.

Dissertation · Machine learning

Hierarchical Image Classification System

A Python pipeline for multi-domain hierarchical image classification, built to handle class imbalance and domain variation. Trained and evaluated with Scikit-learn and TensorFlow, and scored with Confidence-Weighted Hierarchical Distance a metric I designed that weighs taxonomic error severity against model confidence. The 14,000+ image dataset behind it is published on Kaggle with full documentation.

First Class · 82% View the dataset Open source · Python package

hiereval

An evaluation package for hierarchical classification, published to PyPI. It implements the Confidence-Weighted Hierarchical Distance metric from my dissertation alongside set-based, distance-based and structural measures. Zero dependencies, fully typed, with continuous integration across Python 3.9–3.12.
